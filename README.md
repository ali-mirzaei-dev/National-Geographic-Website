# National Geographic Website Clone

A pixel-perfect, fully responsive clone of the National Geographic homepage built as a front-end practice project using **Bootstrap 5** and pure **HTML/CSS**.

## Installation

```bash
# Clone the repository
git clone https://github.com/ali-mirzaei-dev/National-Geographic-Website.git

# Navigate to project directory
cd National-Geographic-Website

# Open with Live Server or open index.html in browser
`````
